全文导读

这篇是开放世界具身智能体论文，数字好看，但主张容易被收成「又一个会玩 Minecraft 的 GPT-4」。下面先给出主张、机制、证据与精读路径。读完这一页，再带着一个具体问题进入正文。

一句话主张。 不调权重，也能在 Minecraft 里终身学习：自动课程出刚好难一点的题，技能库把过关代码存起来再检索，迭代提示用环境反馈、报错和自我验证改程序。

和 AI 工程、智能体的关系

这篇首先是协议 / 循环工作：行动空间是可执行代码，主循环是「出题 → 检索旧技能 → 写代码 → 跑 → 裁判 → 入库」。对 AI 工程的用处可以收成一句：把开放世界里的能力从「每次从头想」变成「越玩越厚的技能库」。

它和 ReAct / Reflexion / AutoGPT 不是同一条路。那些会推理、会反思、会拆子目标，但没有一本可检索、可组合的技能库，也没有由好奇心驱动、自下而上展开的自动课程。Voyager 把技能写成 craftStoneShovel() 这类函数，用描述嵌入检索 Top-5，复杂技能由简单程序拼起来。和 Cordiverse 的关系见读后评论：技能会发明、会复用，卸载与依赖语义还没有。

问题从哪来

开放世界要的是终身学习：按处境出合适任务、把练会的招记下来、自己找新事做。经典 RL / 模仿学习卡在原子动作上；现有 LLM 智能体多半不是能在长时段里积累并迁移知识的终身学习者。Minecraft 没有预定终局，正好当试验场。

另一层压力是：LLM 很难一次写对具身控制代码。缺的不是又一次思维链，而是课程、技能库，以及把环境、解释器、裁判拧在一起的迭代提示。

机制（自动课程 + 技能库 + 迭代提示）

自动课程：发现尽可能多样的事物

GPT-4 看物品栏、群系、饥饿、成败记录，出一道可验证的单短语任务。可视为上下文形式的新颖性搜索。预热日程按过关数一点点加信息。

技能库：代码当技能，嵌入当钥匙

过关程序按描述嵌入放进向量库。新任务先让 GPT-3.5 写建议，再检索 Top-5 旧技能。函数被要求通用、可被更复杂函数复用。

迭代提示最多 4 轮：环境反馈（缺材料）、执行错误（调用了不存在的 acacia_axe）、另一个 GPT-4 当自我验证。过关入库；卡住就换题。人不调权重，只黑盒查 GPT-4。

  • 三件套：自动课程、不断增长的技能库、含三类反馈的迭代提示。

Abstract

We introduce VOYAGER, the first LLM-powered embodied lifelong learning agent in Minecraft that continuously explores the world, acquires diverse skills, and makes novel discoveries without human intervention. VOYAGER consists of three key components: 1) an automatic curriculum that maximizes exploration, 2) an ever-growing skill library of executable code for storing and retrieving complex behaviors, and 3) a new iterative prompting mechanism that incorporates environment feedback, execution errors, and self-verification for program improvement. VOYAGER interacts with GPT-4 via blackbox queries, which bypasses the need for model parameter fine-tuning. The skills developed by VOYAGER are temporally extended, interpretable, and compositional, which compounds the agent’s abilities rapidly and alleviates catastrophic forgetting. Empirically, VOYAGER shows strong in-context lifelong learning capability and exhibits exceptional proficiency in playing Minecraft. It obtains 3.3× more unique items, travels 2.3× longer distances, and unlocks key tech tree milestones up to 15.3× faster than prior SOTA. VOYAGER is able to utilize the learned skill library in a new Minecraft world to solve novel tasks from scratch, while other techniques struggle to generalize. 摘要

我们提出 Voyager，这是第一个由大语言模型驱动的、在 Minecraft 中进行终身学习的具身智能体：它持续探索世界、获取多样化技能，并在无人干预下做出新发现。Voyager 由三个关键组件构成：1）最大化探索的自动课程；2）不断增长的技能库，以可执行代码存储并检索复杂行为；3）一种新的迭代提示机制，把环境反馈、执行错误与自我验证纳入程序改进。Voyager 通过黑盒查询与 GPT-4 交互，无需微调模型参数。它所发展的技能具有时间延展性、可解释性与可组合性，使智能体能力迅速叠加，并缓解灾难性遗忘。

Introduction Building generally capable embodied agents that continuously explore, plan, and develop new skills in open-ended worlds is a grand challenge for the AI community [1–5]. Classical approaches employ reinforcement learning (RL) [6, 7] and imitation learning [8–10] that operate on primitive actions, which could be challenging for systematic exploration [11–15], interpretability [16–18], and generalization [19–21]. Recent advances in large language model (LLM) based agents harness the world knowledge encapsulated in pre-trained LLMs to generate consistent action plans or executable policies [16, 22, 19]. They are applied to embodied tasks like games and robotics [23–27], as well as NLP tasks without embodiment [28–30]. However, these agents are not lifelong learners that can progressively acquire, update, accumulate, and transfer knowledge over extended time spans [31, 32]. Let us consider Minecraft as an example. Unlike most other games studied in AI [33, 34, 10], Minecraft does not impose a predefined end goal or a fixed storyline but rather provides a unique playground with endless possibilities [23]. Minecraft requires players to explore vast, procedurally generated 3D terrains and unlock a tech tree using gathered resources. Human players typically start by learning the basics, such as mining wood and cooking food, before advancing to more complex tasks like combating monsters and crafting diamond tools. We argue that an effective lifelong learning agent should have similar capabilities as human players: (1) propose suitable tasks based on its current skill level and world state, e.g., learn to harvest sand and cactus before iron if it finds itself in a desert rather than a forest; (2) refine skills based on environmental feedback and commit mastered skills to memory for future reuse in similar situations (e.g. fighting zombies is similar to fighting spiders); (3) continually explore the world and seek out new tasks in a self-driven manner. Towards these goals, we introduce VOYAGER, the first LLM-powered embodied lifelong learning agent to drive exploration, master a wide range of skills, and make new discoveries continually without human intervention in Minecraft. VOYAGER is made possible through three key modules (Fig. 2): 1) an automatic curriculum that maximizes exploration; 2) a skill library for storing and retrieving complex behaviors; and 3) a new iterative prompting mechanism that generates executable code for embodied control. We opt to use code as the action space instead of low-level motor commands because programs can naturally represent temporally extended and compositional actions [16, 22], which are essential for many long-horizon tasks in Minecraft. VOYAGER interacts with a blackbox LLM (GPT-4 [35]) through prompting and in-context learning [36–38]. Our approach bypasses the need for model parameter access and explicit gradient-based training or finetuning. More specifically, VOYAGER attempts to solve progressively harder tasks proposed by the automatic curriculum, which takes into account the exploration progress and the agent’s state. The curriculum is generated by GPT-4 based on the overarching goal of “discovering as many diverse things as possible”. This approach can be perceived as an in-context form of novelty search [39, 40]. VOYAGER incrementally builds a skill library by storing the action programs that help solve a task successfully.

引言

构建能够在开放世界中持续探索、规划并发展新技能的通用具身智能体，是人工智能社区的重大挑战[1–5]。经典方法采用在原子动作上运行的强化学习（RL）[6, 7]与模仿学习[8–10]，这在系统探索[11–15]、可解释性[16–18]与泛化[19–21]上往往困难。近期基于大语言模型（LLM）的智能体，利用预训练 LLM 中封装的世界知识，生成一致的行动计划或可执行策略[16, 22, 19]。它们被用于游戏与机器人等具身任务[23–27]，以及无具身的 NLP 任务[28–30]。然而，这些智能体并不是能在长时段里逐步获取、更新、积累并迁移知识的终身学习者[31, 32]。

以 Minecraft 为例。与多数 AI 研究中的游戏不同[33, 34, 10]，Minecraft 不施加预定终局或固定剧情，而是提供一个可能性无穷的独特游乐场[23]。玩家需要探索广阔的程序化生成三维地形，并用采集到的资源解锁科技树。人类玩家通常先学伐木、做饭等基础，再进入打怪、合成钻石工具等更复杂任务。我们认为，有效的终身学习智能体应具备与人类玩家相近的能力：（1）根据当前技能水平与世界状态提出合适任务，例如身处沙漠而非森林时，应先学采集沙子与仙人掌，而不是先学铁；（2）根据环境反馈精炼技能，并把已掌握技能记入记忆，以便在相似情境中复用（例如打僵尸与打蜘蛛相近）；（3）以自我驱动的方式持续探索世界、寻找新任务。

朝向这些目标，我们提出 Voyager，第一个由 LLM 驱动的具身终身学习智能体，在 Minecraft 中无人干预地驱动探索、掌握广泛技能并持续做出新发现。Voyager 通过三个关键模块成为可能（图 2）：1）最大化探索的自动课程；2）用于存储与检索复杂行为的技能库；3）一种新的迭代提示机制，生成用于具身控制的可执行代码。我们选择以代码而非低层运动指令作为行动空间，因为程序能自然表示时间延展且可组合的动作[16, 22]，这对 Minecraft 中许多长时程任务至关重要。Voyager 通过提示与上下文学习与黑盒 LLM（GPT-4 [35]）交互[36–38]。我们的方法无需访问模型参数，也无需显式的基于梯度的训练或微调。

更具体地，Voyager 尝试解决由自动课程提出的、逐步变难的任务；课程会考虑探索进度与智能体状态。课程由 GPT-4 生成，总目标是「发现尽可能多样的事物」。这一做法可视为新颖性搜索的一种上下文形式[39, 40]。Voyager 通过存储成功解题的动作程序，逐步构建技能库。

Complex skills can be synthesized by composing simpler programs, which compounds VOYAGER’s capabilities rapidly over time and alleviates catastrophic forgetting in other continual learning methods [31, 32]. However, LLMs struggle to produce the correct action code consistently in one shot [41]. To address this challenge, we propose an iterative prompting mechanism that: (1) executes the generated program to obtain observations from the Minecraft simulation (such as inventory listing and nearby creatures) and error trace from the code interpreter (if any); (2) incorporates the feedback into GPT-4’s prompt for another round of code refinement; and (3) repeats the process until a self-verification module confirms the task completion, at which point we commit the program to the skill library (e.g., craftStoneShovel() and combatZombieWithSword()) and query the automatic curriculum for the next milestone (Fig. 2). Empirically, VOYAGER demonstrates strong in-context lifelong learning capabilities. It can construct an ever-growing skill library of action programs that are reusable, interpretable, and generalizable to novel tasks. We evaluate VOYAGER systematically against other LLM-based agent techniques (e.g., ReAct [29], Reflexion [30], AutoGPT [28]) in MineDojo [23], an open-source Minecraft AI framework. VOYAGER outperforms prior SOTA by obtaining 3.3× more unique items, unlocking key tech tree milestones up to 15.3× faster, and traversing 2.3× longer distances. We further demonstrate that VOYAGER is able to utilize the learned skill library in a new Minecraft world to solve novel tasks from scratch, while other methods struggle to generalize. Method VOYAGER consists of three novel components: (1) an automatic curriculum (Sec. 2.1) that suggests objectives for open-ended exploration, (2) a skill library (Sec. 2.2) for developing increasingly complex behaviors, and (3) an iterative prompting mechanism (Sec. 2.3) that generates executable code for embodied control. Full prompts are presented in Appendix, Sec. A. 2.1 Automatic Curriculum Embodied agents encounter a variety of objectives with different complexity levels in open-ended environments. An automatic curriculum offers numerous benefits for open-ended exploration, ensuring a challenging but manageable learning process, fostering curiosity-driven intrinsic motivation for agents to learn and explore, and encouraging the development of general and flexible problemsolving strategies [42–44]. Our automatic curriculum capitalizes on the internet-scale knowledge contained within GPT-4 by prompting it to provide a steady stream of new tasks or challenges. The curriculum unfolds in a bottom-up fashion, allowing for considerable adaptability and responsiveness to the exploration progress and the agent’s current state (Fig. 3). As VOYAGER progresses to harder self-driven goals, it naturally learns a variety of skills, such as “mining a diamond”.

3.2

基线

由于没有开箱即用的、面向 Minecraft 的基于 LLM 的智能体，我们尽力选取若干代表性算法作为基线。这些方法原本只为无具身的 NLP 任务设计，因此必须重新诠释，使其能在 MineDojo 中执行并与我们的实验设置兼容：

ReAct [29] 用思维链提示[46]，由 LLM 同时生成推理轨迹与行动计划。我们向它提供环境反馈与智能体状态作为观察。

Reflexion [30] 建立在 ReAct [29] 之上，用自我反思推断更直观的未来行动。我们向它提供执行错误以及我们的自我验证模块。

AutoGPT [28] 是流行的软件工具，通过把高层目标分解为多个子目标，并在 ReAct 风格循环中执行，来自动化 NLP 任务。我们用 GPT-4 做任务分解并重新实现 AutoGPT，在子目标执行时提供智能体状态、环境反馈与执行错误作为观察。与 Voyager 相比，AutoGPT 缺少用于积累知识的技能库、用于评估任务成功的自我验证，以及用于开放式探索的自动课程。

注意，我们不直接与以 Minecraft 屏幕像素为输入、输出低层控制的先前方法比较[53–55]。那不会是公平比较，因为我们依赖高层 Mineflayer [52] API 控制智能体。本文重点是把 GPT-4 推向终身具身智能体学习的极限，而不是解决三维感知或感觉运动控制问题。Voyager 与之正交，只要控制器提供代码 API，就可与 VPT [8] 等基于梯度的方法结合。

Limitations and Future Work Cost. The GPT-4 API incurs significant costs. It is 15× more expensive than GPT-3.5. Nevertheless, VOYAGER requires the quantum leap in code generation quality from GPT-4 (Fig. 9), which GPT-3.5 and open-source LLMs cannot provide [60]. Inaccuracies. Despite the iterative prompting mechanism, there are still cases where the agent gets stuck and fails to generate the correct skill. The automatic curriculum has the flexibility to reattempt this task at a later time. Occasionally, self-verification module may also fail, such as not recognizing spider string as a success signal of beating a spider. Hallucinations. The automatic curriculum occasionally proposes unachievable tasks. For example, it may ask the agent to craft a “copper sword" or “copper chestplate", which are items that do not exist within the game. Hallucinations also occur during the code generation process. For instance, GPT-4 tends to use cobblestone as a fuel input, despite being an invalid fuel source in the game. Additionally, it may call functions absent in the provided control primitive APIs, leading to code execution errors. We are confident that improvements in the GPT API models as well as novel techniques for finetuning open-source LLMs will overcome these limitations in the future. Related work Decision-making Agents in Minecraft. Minecraft is an open-ended 3D world with incredibly flexible game mechanics supporting a broad spectrum of activities. Built upon notable Minecraft benchmarks [23, 61–65], Minecraft learning algorithms can be divided into two categories: 1) Low-level controller: Many prior efforts leverage hierarchical reinforcement learning to learn from human demonstrations [66–68]. Kanitscheider et al. [14] design a curriculum based on success rates, but its objectives are limited to curated items. MineDojo [23] and VPT [8] utilize YouTube videos for large-scale pre-training. DreamerV3 [69], on the other hand, learns a world model to explore the environment and collect diamonds. 2) High-level planner: Volum et al. [70] leverage few-shot prompting with Codex [41] to generate executable policies, but they require additional human interaction. Recent works leverage LLMs as a high-level planner in Minecraft by decomposing a high-level task into several subgoals following Minecraft recipes [55, 53, 71], thus lacking full exploration flexibility. Like these latter works, VOYAGER also uses LLMs as a high-level planner by prompting GPT-4 and utilizes Mineflayer [52] as a low-level controller following Volum et al. [70]. Unlike prior works, VOYAGER employs an automatic curriculum that unfolds in a bottom-up manner, driven by curiosity, and therefore enables open-ended exploration. Large Language Models for Agent Planning. Inspired by the strong emergent capabilities of LLMs, such as zero-shot prompting and complex reasoning [72, 37, 38, 36, 73, 74], embodied agent research [75–78] has witnessed a significant increase in the utilization of LLMs for planning purposes. Recent efforts can be roughly classified into two groups. 1) Large language models for robot learning: Many prior works apply LLMs to generate subgoals for robot planning [27, 27, 25, 79, 80]. Inner Monologue [26] incorporates environment feedback for robot planning with LLMs. Code as Policies [16] and ProgPrompt [22] directly leverage LLMs to generate executable robot policies. VIMA [19] and PaLM-E [59] fine-tune pre-trained LLMs to support multimodal prompts. 2) Large language models for text agents: ReAct [29] leverages chain-of-thought prompting [46] and generates both reasoning traces and task-specific actions with LLMs. Reflexion [30] is built upon ReAct [29] with self-reflection to enhance reasoning. AutoGPT [28] is a popular tool that automates NLP tasks by crafting a curriculum of multiple subgoals for completing a high-level goal while incorporating ReAct [29]’s reasoning and acting loops. DERA [81] frames a task as a dialogue between two GPT-4 [35] agents. Generative Agents [82] leverages ChatGPT [50] to simulate human behaviors by storing agents’ experiences as memories and retrieving those for planning, but its agent actions are not executable. SPRING [83] is a concurrent work that uses GPT-4 to extract game mechanics from game manuals, based on which it answers questions arranged in a directed acyclic graph and predicts the next action. All these works lack a skill library for developing more complex behaviors, which are crucial components for the success of VOYAGER in lifelong learning. Code Generation with Execution. 不准确。即便有迭代提示机制，智能体仍有卡住、写不出正确技能的情况。自动课程可以稍后重新尝试该任务。自我验证模块偶尔也会失败，例如不把蜘蛛丝识别为击败蜘蛛的成功信号。

幻觉。自动课程偶尔提出无法完成的任务。例如，它可能要求智能体合成「铜剑」或「铜胸甲」——游戏中并不存在的物品。代码生成过程中也会出现幻觉。例如，GPT-4 倾向把圆石当作燃料，尽管它在游戏中不是有效燃料。此外，它可能调用所提供控制原语 API 中不存在的函数，导致代码执行错误。我们相信，GPT API 模型的改进以及微调开源 LLM 的新技术，将在未来克服这些局限。

相关工作

Minecraft 中的决策智能体。

Minecraft 是开放式三维世界，游戏机制极为灵活，支持广泛活动。建立在若干著名 Minecraft 基准之上[23, 61–65]，Minecraft 学习算法可分为两类：1）低层控制器：许多先前工作用分层强化学习从人类示范中学习[66–68]。Kanitscheider 等人[14] 按成功率设计课程，但目标限于精心挑选的物品。MineDojo [23] 与 VPT [8] 利用 YouTube 视频做大规模预训练。DreamerV3 [69] 则学习世界模型以探索环境并采集钻石。2）高层规划器：Volum 等人[70] 用 Codex [41] 少样本提示生成可执行策略，但需要额外的人类交互。近期工作把 LLM 当作 Minecraft 中的高层规划器，按配方把高层任务拆成若干子目标[55, 53, 71]，因而缺少完整的探索灵活性。与这些后者一样，Voyager 也通过提示 GPT-4 把 LLM 当作高层规划器，并遵循 Volum 等人[70] 用 Mineflayer [52] 作为低层控制器。与先前工作不同，Voyager 采用由好奇心驱动、自下而上展开的自动课程，从而实现开放式探索。

用于智能体规划的大语言模型。

受 LLM 强涌现能力（如零样本提示与复杂推理）启发[72, 37, 38, 36, 73, 74]，具身智能体研究[75–78] 中用 LLM 做规划的工作显著增加。近期努力大致分两组。1）用于机器人学习的大语言模型：许多先前工作用 LLM 为机器人规划生成子目标[27, 27, 25, 79, 80]。Inner Monologue [26] 把环境反馈纳入基于 LLM 的机器人规划。Code as Policies [16] 与 ProgPrompt [22] 直接用 LLM 生成可执行机器人策略。VIMA [19] 与 PaLM-E [59] 微调预训练 LLM 以支持多模态提示。2）用于文本智能体的大语言模型：ReAct [29] 借助思维链提示[46]，用 LLM 同时生成推理轨迹与任务特定动作。Reflexion [30] 建立在 ReAct [29] 之上，用自我反思增强推理。AutoGPT [28] 是流行工具，通过为完成高层目标制定多个子目标的课程，并纳入 ReAct [29] 的推理–行动循环，来自动化 NLP 任务。DERA [81] 把任务建成两个 GPT-4 [35] 智能体之间的对话。生成式智能体[82] 用 ChatGPT [50] 通过把智能体经历存为记忆并检索来规划，以模拟人类行为，但其智能体动作不可执行。SPRING [83] 是同期工作，用 GPT-4 从游戏手册抽取游戏机制，据此回答按有向无环图排列的问题并预测下一步动作。这些工作都缺少用于发展更复杂行为的技能库，而技能库是 Voyager 在终身学习上成功的关键组件。

B.2

基线

ReAct [29] 用思维链提示[46]，由 LLM 同时生成推理轨迹与行动计划。我们向它提供环境反馈与智能体状态作为观察。ReAct 先从零做一轮代码生成，再做三轮精炼，然后重复直到达到最大提示迭代。

Reflexion [30] 建立在 ReAct [29] 之上，用自我反思推断更直观的未来行动。我们向它提供环境反馈、智能体状态、执行错误以及我们的自我验证模块。与 ReAct 类似，Reflexion 从零一轮生成再三轮精炼，重复直到最大迭代。

AutoGPT [28] 是流行软件工具，通过把高层目标分解为多个子目标并在 ReAct 风格循环中执行来自动化 NLP 任务。我们用 GPT-4 做任务分解并重新实现 AutoGPT，在子目标执行时提供智能体状态、环境反馈与执行错误。与 Voyager 相比，AutoGPT 缺少积累知识的技能库、评估成功的自我验证，以及开放式探索的自动课程。每个子目标执行时，若无执行错误则视为完成并进入下一个；否则精炼程序直到三轮（等价四轮代码生成）完成再进入下一子目标。若连续三个子目标都未获得新物品，则重新运行任务分解以再规划。

它解决的是「每次从头写」，不是「可组合的运行时」

Voyager 的现场很清楚：自动课程出题，技能库把过关的 JavaScript 函数按描述嵌入存起来，新任务检索 Top-5，迭代提示用环境、报错和自我验证改到过关为止。这是运行中的技能发明与复用——行动空间跟着探索进度长，而不是开跑前焊死一套原子动作。

Cordiverse 要的却是另一层保证：卸掉时把副作用干净收回（时间可组合性），以及依赖能声明、能发现、能随变化自动协调（空间可组合性）。这篇论文没有这两刀。技能写进向量库、被调用、被组合成更复杂的函数；换一张新地图可以带着库再出发，但没有卸载语义、没有依赖规约、也没有「一条坏技能如何隔离爆炸半径」。技能库因此是动态组合的半截：组合发生了，回收与协调还没有。

库会变厚，但不会过期

提示 4 要求函数通用、可复用，使用前检查背包，不要对物品栏做强假设。这是组合友好的写法。可是库本身只增不减：过关就 add_skill，没有「这条过期了、与另一条冲突了、权限该一并撤掉」。自我验证看的是最终背包和饥饿，不看技能之间谁依赖谁。检索 Top-5 准确率 96.5% 说明找得到旧图纸，不说明旧图纸在世界变了之后仍然该被调用。

作者自己写下的幻觉——铜剑、圆石当燃料、调用不存在的 API——正是没有依赖与验收闸门时的典型事故。迭代提示能改到过关，过关之后技能就成了库里的永久居民。

作者自己点名、但仍开放的

  • 视觉与空间细节：当时 GPT-4 API 纯文本。三维建造要靠人当裁判或当课程。多模态是展望。
  • 成本与模型门槛：GPT-4 贵 15 倍但换不掉；GPT-3.5 写代码独特物品只剩约 1/5.7。开放技能合成把编码能力变成一等门槛。
  • 不准确与幻觉：4 轮仍会卡住；自我验证会漏判；课程会出不存在的物品。改进寄托于更好的 GPT 与开源微调，不是运行时约束。

一句话判断

价值在于证明：不必微调权重，自动课程 + 技能库 + 三类反馈的迭代提示，就能在 Minecraft 里持续发现、点亮科技树，并把技能库搬到新世界。缺口是：这是没有卸载保证、没有依赖语义的技能发明；库只增不减；幻觉过关后仍会留下。Cordiverse 要补的，正是这篇还没承诺的那半截。
